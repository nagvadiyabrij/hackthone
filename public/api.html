NEXORA backend API

Local base URL: http://localhost:3000

This local development server uses HTTP. HTTPS requires a domain and TLS certificate, so it is not enabled locally.

Available routes

MethodRoutePurpose
POST/api/auth/loginStart a session
POST/api/auth/registerCreate an account
POST/api/auth/logoutEnd the current session
GET/api/meCurrent user and workspace state
GET/api/eventsRealtime event stream
POST/api/projectsCreate a project
POST/api/tasksCreate a task
PATCH / DELETE/api/tasks/:idUpdate or delete a task
